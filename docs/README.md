## The three golden rules

1. **Nothing is lost.** Every change is saved in GitHub's history and can be undone (see [08 · Fix problems](08-fix-problems.md), "Undo a change").
2. **Publishing = saving to the `main` branch.** About two minutes after a change reaches `main`, the live site updates by itself.
3. **When unsure, use a pull request.** A pull request lets you look at a change before it goes live (see [06](06-pull-requests.md)).
