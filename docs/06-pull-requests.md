# 06 · Pull requests: review and publish

[Back to the handbook](README.md)

Claude (or any helper) usually proposes changes as a **pull request**, so nothing goes live without you.

1. Open <https://github.com/kritikesh28/kritikesh28.github.io/pulls>. Each open pull request is a proposed change.
2. Click one. The first tab, **Conversation**, explains what it does.
3. Click **Files changed** to see every line: green = added, red = removed.
4. To leave a note on a line, hover it and click the blue **+**.
5. To change something yourself: in **Files changed**, click the three dots on the file › **Edit file**, edit, and commit to the same branch.
6. To publish: back on **Conversation**, click **Merge pull request** › **Confirm merge**. Then check the **Actions** tab for a green tick.
7. To reject it: click **Close pull request** at the bottom. Nothing changes on the site.

After merging, GitHub offers **Delete branch**. It is safe to click; the change is already in `main`.
