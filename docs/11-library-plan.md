# 11 · Library plan

[Back to the handbook](README.md)

The blog is growing into an **open library for curious minds**: every subject broken into short, connected pages, from the most basic question up to expert depth. The full blueprint is a Claude Doc, "Curious Sparoows Library: blueprint". This page is the summary you can rely on without it.

## Page types for each unit (for example "Universe")

| Page | Length | Purpose | In Google? |
| --- | --- | --- | --- |
| **Gateway** | 1 min | What you'll know by the end, number of parts, total time | Yes |
| **Leaf** | 1 to 2 min | One question answered fully, a strong opening question, an honest hook to the next page | Yes |
| **Full Journey** | 10 to 25 min | All Leaves of the unit on one page, for reading at once | No (avoids duplicate content) |
| **Recap** | 1 min | The unit in 10 lines, a 5-question self-check, link to the next unit | Yes |

## Levels: the knowledge tree (recommended 25 October 2026, waiting for final OK)

| Level | Name on the site | Example |
| --- | --- | --- |
| The whole library | **Forest** | Curious Sparoows Forest |
| Course (subject) | **Tree** | Geography Tree, AI Tree |
| Module | **Branch** | Geomorphology Branch |
| Section | **Twig** | Landforms made by rivers |
| Chapter, topic, subtopic | headings inside a Twig | River valleys, V-shaped valleys |
| One short page (1 to 2 min) | **Leaf** | Why is a young valley shaped like a V? |

Why a tree: everyone understands it at once (a branch grows from a tree, a leaf from a twig), it fits the sparrows who live in trees, and it is literally true as a picture of how knowledge grows. The cosmic names were dropped because galaxy, constellation and planet don't contain each other that way, and a science library shouldn't teach a wrong picture.

Rules: plain words always shown with the tree words in the breadcrumb ("Geography Tree › Geomorphology Branch"); menus show at most three levels at once; a small "How this library works" panel explains the names to every new visitor.

## Build phases

1. **Foundation:** the four page types, Next/Previous buttons, progress bar, search that never says "no match found", first 12 Universe Leaves.
2. **Explorer** (after the first unit): the Curiosity Orbit on the home page plus a plain directory, Hindi and Hinglish search words, tracking of empty searches.
3. **Grow** (after about 100 Leaves and a steady weekly rhythm): a map of links between subjects, an AI answer box that uses only the site's own pages, newsletter and quizzes, Hindi Leaves.
