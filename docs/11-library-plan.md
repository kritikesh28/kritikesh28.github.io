# 11 · Library plan

[Back to the handbook](README.md)

The blog is growing into an **open library for curious minds**: every subject broken into short, connected pages, from the most basic question up to expert depth. The full blueprint is a Claude Doc, "Curious Sparoows Library: blueprint". This page is the summary you can rely on without it.

## Page types for each unit (for example "Universe")

| Page | Length | Purpose | In Google? |
| --- | --- | --- | --- |
| **Gateway** | 1 min | What you'll know by the end, number of parts, total time | Yes |
| **Leaf** | 1 to 2 min | One question answered fully, a strong opening question, an honest hook to the next page | Yes |
| **Full Journey** | 10 to 25 min | All Leaves of the unit on one page, for reading at once | No (avoids duplicate content) |
| **Recap** | 1 min | The unit in 10 lines, a 5-question self-check, link to the next unit | Yes |

## Levels: the knowledge tree (in use on the site since 25 October 2026)

| Level | Name on the site | Example |
| --- | --- | --- |
| The whole library | **Forest** | Curious Sparoows Forest |
| Course (subject) | **Tree** | Geography Tree, AI Tree |
| Module | **Branch** | Geomorphology Branch |
| Chapter (a short course) | **Twig** | The Universe; Landforms made by rivers |
| Topic, subtopic | headings inside a Leaf | Not a bomb in the dark |
| One short page (1 to 2 min) | **Leaf** | Why is a young valley shaped like a V? |

Why a tree: everyone understands it at once (a branch grows from a tree, a leaf from a twig), it fits the sparrows who live in trees, and it is literally true as a picture of how knowledge grows. The cosmic names were dropped because galaxy, constellation and planet don't contain each other that way, and a science library shouldn't teach a wrong picture.

Rules: plain words always shown with the tree words in the breadcrumb ("Geography Tree › Geomorphology Branch"); menus show at most three levels at once; a small "How this library works" panel explains the names to every new visitor.

## Build phases

1. **Foundation:** the four page types, Next/Previous buttons, progress bar, the Curious Question card, search that never says "no match found", the "How this library works" panel, first 12 Universe Leaves.
2. **Explorer** (after the first unit): reading progress tracker (private, in the reader's browser, no guilt-streaks), the knowledge-tree explorer on the home page plus a plain directory, Hindi and Hinglish search words, quiet counting of searches that found little.
3. **Grow** (after about 100 Leaves and a steady weekly rhythm): a map of links between subjects, newsletter and quizzes, Hindi Leaves.

**Alongside all phases:** the AI Sparrow Assistant, Kritikesh's AI showcase project. Stages: design, prototype, launch. See [12 · Pending task list](12-task-list.md).

## What is built (25 October 2026)

Phase 1 and the reading tracker from phase 2 are live in the library update: the four page types, the Universe twig (Gateway, 12 Leaves, Full Journey, Recap with a 12-question self-check), Next/Previous, progress dots, the guide panel, the Curious Question card (24 questions), reading progress, and site search. How to add to it: [13 · Add to the library](13-add-to-the-library.md).

One change from the plan: search is built into the site instead of using Pagefind. With a few hundred pages, a small search file is faster, needs no extra tool, works with the site's strict security settings, and lets us control the "never empty" behaviour exactly. Revisit Pagefind when the library passes about 1,000 pages.
